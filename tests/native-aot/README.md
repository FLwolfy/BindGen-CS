NativeAOT requires 113 checks across FunctionTable, DllImport and LibraryImport, including independently compared aggregate results and generated call-scoped managed callback capture/exception boundaries. Browser interpreter/AOT retain their separate 74-check matrix; desktop aggregate support does not certify a browser ABI. All original raw callback cases remain. No generated source is edited.

The current source also requires original-address alias checks for ref/ref, in/out, record fields and overlapping Span/ref inputs. Each compares independently observed native pointer identity and ordered mutations. Earlier 101/62 receipts remain historical evidence; they cannot certify the expanded 113/74 matrix.
