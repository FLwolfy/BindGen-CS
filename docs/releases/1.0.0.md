# BGCS 1.0.0

## Architecture and extensibility

- Expand configuration coverage for both C# binding generation and the C++ bridge generator.
- Refine runtime support and remove empty generated partial classes.

## Parser portability

- Correct boolean type generation.
- Add automatic configuration documentation generation.

## Verification and packaging

- Expand configuration-entry tests, including compilation of generated code.
- Archive the three original NuGet packages without regenerating bindings or rebuilding assemblies.

## Requirements and scope

This release targets .NET 9. Use the documentation and configuration from this tagged source.

Matching `BGCS.Core` and `BGCS.Language` 1.0.x dependency packages were not published to NuGet. Their absence is preserved in the archive report; retrieving these original packages does not establish a complete, runnable generator dependency closure.

## Release provenance

Source: [`v1.0.0`](https://github.com/FLwolfy/BindGen-CS/tree/9286f44d2ea4a409f3431a3613a838eeea0a152e) (`9286f44d2ea4a409f3431a3613a838eeea0a152e`).

Release assets are copies of the original NuGet packages, plus `release-archive.json` and `SHA256SUMS`. Historical symbol packages and build attestations are not reconstructed. This archive does not assert that the original source passed today's CI.
