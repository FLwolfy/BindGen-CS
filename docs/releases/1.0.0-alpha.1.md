# BGCS 1.0.0-alpha.1

## Architecture and extensibility

- Introduce public `BGCS` and `BGCS.Cpp2C` packages alongside the separate runtime library.
- Provide C header bindings and C++-to-C bridge generation through the existing configuration model.

## Parser portability

- Consolidate generated runtime namespaces and remove duplicate namespace output.

## Verification and packaging

- Add initial tests and public member documentation.
- Archive the three original NuGet packages with their source metadata and SHA-256 checksums.

## Requirements and scope

This is the original generator prerelease. It targets .NET 9 and retains the historical API and configuration.

Matching `BGCS.Core` and `BGCS.Language` 1.0.x dependency packages were not published to NuGet. Their absence is preserved in the archive report; retrieving these original packages does not establish a complete, runnable generator dependency closure.

## Release provenance

Source: [`v1.0.0-alpha.1`](https://github.com/FLwolfy/BindGen-CS/tree/0d3340f2b3c6779246959c221060a8c6b20b3984) (`0d3340f2b3c6779246959c221060a8c6b20b3984`).

Release assets are copies of the original NuGet packages, plus `release-archive.json` and `SHA256SUMS`. Historical symbol packages and build attestations are not reconstructed. This archive does not assert that the original source passed today's CI.
