# BGCS 2.0.3

## Architecture and extensibility

- Publish the generator and its implementation packages as a dependency closure.
- Retain IR-native C# emission, typed C++ lowering, and ABI safety analysis.

## Parser portability

- Align the NuGet package acceptance results on Linux.

## Verification and packaging

- Archive seven original library packages from NuGet.
- Validate each package's ID, version, repository commit, ZIP integrity, and archive checksum.
- This version did not publish the `BindGen-CS` .NET tool package.

## Requirements and scope

The libraries target .NET 9. Historical packages and source retain the 2.0.x contracts.

## Release provenance

Source: [`v2.0.3`](https://github.com/FLwolfy/BindGen-CS/tree/895a309f49f09e924976ad716404d4731107be73) (`895a309f49f09e924976ad716404d4731107be73`).

Release assets are copies of the original NuGet packages, plus `release-archive.json` and `SHA256SUMS`. Historical symbol packages and build attestations are not reconstructed. This archive does not assert that the original source passed today's CI.
