# BGCS 4.1.0

## Architecture

BGCS remains a source generator: C/C++ declarations and local rules produce C#,
necessary native bridge sources, manifests and diagnostics. Consumer projects
continue to own compilation, linking, deployment and execution. Core interfaces,
explicit extensions and the independent Runtime retain their 4.x contracts.

This release consolidates current documentation and archives the pre-release
working ledger. Native shim and allocator examples take the library path supplied
by the consumer; they no longer imply that BGCS creates native binaries. Current
configuration examples use the actual `bridge` and `bridge.cpp` groups. The native
shim example parses its public C ABI while the consumer compiles its private C++
implementation; the existing CLI baseline verifies the resulting call.

## Parser

The locked LLVM / ClangSharp versions and native parser resources are unchanged.
The Intel macOS parser supplement remains a generator-host resource, separate
from binding targets and application Runtime dependencies.

## Verification

Source formatting preserves C# syntax tokens, inactive branches and literal
contents. Generated single-file C# uses deterministic LF line endings and
four-space indentation, matching split output. Runtime package and source modes
retain applicable MIT permission text, including after namespace and single-file
composition. Documentation contract checks reject obsolete product commands,
missing links and examples that copy nonexistent native binary outputs.

Release acceptance requires the same-revision Windows baseline, Linux and macOS
smoke checks and installed-product baseline. The release workflow verifies their
receipts and publishes the accepted package bytes; this note alone is not proof
that those gates have completed.

## Requirements

.NET 10 / C# 14; C17 and C++23 defaults. The complete generator supports explicit
extensions without adding consumer build, MSBuild integration or remote setup.
See [getting started](https://github.com/FLwolfy/BindGen-CS/blob/main/docs/getting-started.md),
[packages](https://github.com/FLwolfy/BindGen-CS/blob/main/docs/packages.md) and
[capabilities](https://github.com/FLwolfy/BindGen-CS/blob/main/docs/capabilities.md).

## Provenance

Public packages bind to the accepted source revision. Package payload hashes,
parser provenance, licenses and clean-consumer receipts remain part of the
publication evidence. Historical tags and published 4.0.0 packages are unchanged.
