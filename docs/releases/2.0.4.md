# BGCS 2.0.4

## Architecture and extensibility

- Add the `BindGen-CS` tool pointer package and five RID-specific tool packages to the seven-library release set.

## Parser portability

- Resolve the installed tool shim by platform.
- Skip installed-tool checks on hosts without a published tool RID.

## Verification and packaging

- Publish NuGet packages using GitHub OIDC trusted publishing.
- Archive the thirteen original NuGet packages and record each package's actual repository commit.

## Requirements and scope

Assemblies target .NET 9. The RID-specific tool packaging format requires the .NET 10 SDK for installation.

The seven library packages record commit `5dcda7c4bb8a99d1fa273541aad8a2b9efc97c88`; the tool packages record the release tag's commit `d36b780f4a17d87c33dfb1e876e161f0550351cf`. The archive preserves these original metadata values.

## Release provenance

Source: [`v2.0.4`](https://github.com/FLwolfy/BindGen-CS/tree/d36b780f4a17d87c33dfb1e876e161f0550351cf) (`d36b780f4a17d87c33dfb1e876e161f0550351cf`).

Release assets are copies of the original NuGet packages, plus `release-archive.json` and `SHA256SUMS`. Historical symbol packages and build attestations are not reconstructed. This archive does not assert that the original source passed today's CI.
