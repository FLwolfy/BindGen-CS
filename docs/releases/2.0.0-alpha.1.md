# BGCS 2.0.0-alpha.1

## Architecture and extensibility

- Introduce the IR-native C# emission path and opaque-storage ABI safety checks.
- Expand typed lowering and plugin extension mechanisms.
- Organize the CLI, generator, runtime, intermediate model, and parser projects.

## Parser portability

- Include the desktop host acceptance and generated-output adjustments recorded in the original 2.0.0 source tag.

## Verification and packaging

- This source snapshot did not reach NuGet publication and is archived as an alpha release.
- GitHub provides the source ZIP and tarball; no historical binary packages are attached.

## Requirements and scope

The tagged source targets .NET 9. This alpha archive has not been rebuilt or certified by the 2.1.0 acceptance matrix.
